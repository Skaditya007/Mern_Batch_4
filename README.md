# Mern_Batch_4
This is a practice and learning repository for the MERN Stack (MongoDB, Express, React, Node.js) — built as part of a training batch or self-learning process.

#Project Goals

- Learn and build full-stack applications using the MERN stack.
- Practice REST API development with Express and Node.js.
- Integrate MongoDB for data persistence.
- Develop dynamic front-end interfaces using React.
- Apply modern web development techniques and tools.
